Descripción detallada

Repositorio encargado de las operaciones de persistencia para el catálogo de productos. Gestiona directamente el acceso a la base de datos para la entidad Productos, incluyendo la carga de relaciones con Géneros y Tarifas, y el control de niveles de stock.
